# Pokédoro

> Um aplicativo de produtividade que une o método **Pomodoro** à gamificação do universo **Pokémon** para ajudar você a manter o foco nos estudos e tarefas.

---

## 📌 Sobre o Projeto

O **PokéDoro** foi desenvolvido como o **projeto final do curso**, com o objetivo de resolver um problema comum: manter a concentração durante sessões de estudo ou trabalho. 

Utilizando a técnica Pomodoro (intervalos de trabalho focado seguidos de pequenas pausas), a aplicação transforma o tempo de foco em uma jornada interativa onde você avança na sua rotina enquanto interage com o universo Pokémon.

---

## ✨ Funcionalidades

- [x] **Timer Pomodoro:** Ciclos configuráveis de foco (ex: 25 min) e pausas curtas/longas.
- [x] **Gamificação:** Acompanhamento do progresso e conquistas a cada ciclo de foco concluído.
- [x] **Controle do Timer:** Funções para Iniciar, Pausar e Resetar o temporizador.
- [x] **Interface Temática:** Layout dinâmico inspirado nos jogos e na estética Pokémon.
---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

- **Front-End:** HTML5, CSS3, JavaScript (ES6+)
- **Consumo de Dados / API:** [PokéAPI](https://pokeapi.co/)
- **Versionamento:** Git & GitHub
